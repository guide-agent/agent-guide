## 面试题：怎样计算 Agent 的真实成本？

### 回答框架

不能只统计最后一次模型响应。一次任务可能包含规划、重试、子 Agent、检索、重排序、工具服务和人工接管。核心指标是满足质量门槛的单位成功任务成本，同时观察成本分布，避免平均值掩盖少数失控任务。

### 关键机制与取舍

- 按供应商 usage 与计费规则区分输入、输出、缓存和其他计费项，不用字符数代替账单。
- 任务维度汇总所有分支与失败尝试，记录模型和价格版本，费用估算与真实账单分开。
- 同时看成功率、P95 成本、耗时和转人工成本，不能只以少用 token 判定优化。

### 场景与失败处理

压缩工具描述节省了输入，却导致更多错误调用和重试。应比较端到端单位成功成本，而不是单次请求 token。

### 常见追问

**离线估算准吗？** 可作预算，但需用线上 usage 和账单校准，尤其是缓存与隐含计费项。

**预算耗尽怎么返回？** 报告已完成部分、未完成项与花费状态，不能伪装为任务成功。
