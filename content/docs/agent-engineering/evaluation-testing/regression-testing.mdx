## 面试题：改了一个提示词，为什么还要回归相邻功能？

### 回答框架

提示、工具描述、模型版本和检索策略都可能改变决策分布。回归集要保留曾经失败的最小样例，也要覆盖相邻成功行为。只在新题上通过，不能证明没有破坏旧能力。

### 关键机制与取舍

- 将生产故障转为固定初始状态、输入和判定规则，记录修复前后结果。
- 分别对模型、提示、工具和数据版本打标，一次变更尽量控制变量。
- 设置质量门槛与安全硬失败，成本回归也要纳入检查，避免用十倍重试换小幅成功率。

### 场景与失败处理

为了避免越权把提示改得极严，正常授权查询也被大量拒绝。回归应同时包括越权拒绝和合法访问，报告误拒与漏拒。

### 常见追问

**回归集会过拟合吗？** 会，应保留冻结集和独立新样本，定期检查分布变化。

**失败用例能删除吗？** 只有业务前提确实变化并记录理由时，不为让指标变好直接移除。
