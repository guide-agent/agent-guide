## 面试题：Agent 测试如何分层，才能既稳定又贴近真实行为？

### 回答框架

单元测试验证纯逻辑和状态转换，契约测试验证模型与工具适配，集成测试验证真实依赖交互，端到端评测验证用户目标。模型输出有不确定性，不代表所有测试都必须依赖在线模型；应尽量把确定性边界独立测试。

### 关键机制与取舍

- 对参数校验、预算、幂等与权限使用确定性输入断言，覆盖失败与边界。
- 使用录制或模拟工具结果复现超时、部分成功和异常格式，避免测试真实生产写操作。
- 保留少量受控真实模型与外部服务测试，发现仅靠 mock 看不到的协议漂移。

### 场景与失败处理

所有单测都 mock 为成功，生产中流式参数截断导致异常。应补全截断、重复片段、拒绝和连接中断契约样例，再验证最终动作不会提前执行。

### 常见追问

**如何避免脆弱的文本断言？** 优先校验结构、事实、状态和必要约束，不要求开放答案逐字一致。

**覆盖率高就够吗？** 代码覆盖不能代表任务覆盖，还需风险场景与模型行为评测。
