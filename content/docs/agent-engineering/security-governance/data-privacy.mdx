## 面试题：Agent 数据隐私应该覆盖哪些生命周期？

### 回答框架

不只看模型调用是否加密，还要看采集、检索、上下文、日志、缓存、长期记忆、导出和删除。最小化收集与传播，明确数据是否允许送给当前服务与地域，不能把“使用 API”自动等同于“被训练”或“绝不留存”。

### 关键机制与取舍

- 分类识别个人信息、凭证和业务敏感内容，按场景脱敏或避免发送。
- 检索、缓存和记忆绑定租户及用户范围，删除时追踪衍生副本和索引。
- 核查供应商实际条款与配置，留存期限、训练用途和审计权限分别确认。

### 场景与失败处理

调试日志保存了完整客户合同，应用本身权限正确却通过日志泄露。应缩减字段、控制访问与期限，并提供必要的审计关联而非全文复制。

### 常见追问

**本地模型就没有隐私风险吗？** 仍可能有日志、向量库、插件、备份和权限问题。

**脱敏会影响答案吗？** 可能，需针对任务保留必要语义并评测，不盲目删除所有上下文。
