## 面试题：模型路由如何兼顾质量、费用和可用性？

### 回答框架

先按能力与合规条件筛出可用模型，再根据任务难度、延迟和费用选择。路由器需要额外成本与误判风险，只有端到端收益高于这些开销才值得引入。回退模型必须具备当前步骤所需能力。

### 关键机制与取舍

- 以代表性任务评估各候选，不把参数规模或公开榜单直接当业务表现。
- 为低置信度分类设置升级路径，记录选择理由与实际完成情况。
- 流量突增时控制并发和限额，跨供应商回退同时检查工具、结构化输出与数据边界。

### 场景与失败处理

便宜模型处理简单分类，复杂合同分析升级到更适合模型；但若合同禁止外发，不能因本地模型超时就回退到外部服务。

### 常见追问

**路由模型本身错了怎么办？** 后续验收与风险规则仍要拦截，并用失败样例修正策略。

**怎么衡量收益？** 比较同质量门槛下单位成功任务成本、尾延迟和高风险错误率。
