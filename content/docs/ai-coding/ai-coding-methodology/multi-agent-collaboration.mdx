## 面试题：多个编码 Agent 如何避免互相覆盖工作？

### 回答框架

先识别可并行的独立任务，再划分文件或接口所有权，约定产物和集成方式。共享工作区中，多个 Agent 的修改立即互相可见，不能假定各自拥有隔离副本。真正收益要扣除沟通、等待和集成成本。

### 关键机制与取舍

- 冻结公共契约或由单一负责人修改，避免两个角色同时重写相同接口。
- 交接说明已改文件、验证命令、未完成项与风险，不只报“完成”。
- 集成者检查完整差异并跑跨模块测试，单个分支局部通过不代表整体可用。

### 场景与失败处理

一个 Agent 改函数签名，另一个按旧签名写测试。应明确接口版本并及时同步，冲突时停止相关写入，由指定负责人合并。

### 常见追问

**什么时候不该并行？** 任务有强依赖、改动集中同一文件或验收无法分开时。

**成本如何衡量？** 统计所有角色的调用、重试和集成耗时，与同预算单 Agent 比较。
