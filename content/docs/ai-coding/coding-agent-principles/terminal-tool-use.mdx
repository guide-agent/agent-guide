## 面试题：终端工具如何把命令建议变成可验证执行？

### 回答框架

终端工具应明确工作目录、参数、环境、超时和权限，返回退出码与必要输出。模型声称运行了命令不是证据，启动进程也不等于命令完成。长任务需要会话标识、取消和结果查询机制。

### 关键机制与取舍

- 优先执行已授权且范围明确的命令，网络、安装、外部写入和破坏性动作单独审视。
- 区分标准输出、错误输出、退出码和进行中状态，输出截断时保留完整日志入口。
- 不要把仓库脚本视为天然可信，读取其副作用并在合适隔离环境运行。

### 场景与失败处理

构建命令返回进程 ID 后 Agent 立即报告成功，但实际稍后失败。应等待终态、读取错误并确认产物，必要时说明未完成的外部依赖。

### 常见追问

**退出码为零一定达到需求吗？** 不一定，命令可能未覆盖目标或仅启动后台任务，还需业务验收。

**命令挂起怎么办？** 检查进程与日志，有限等待和重试，仅停止本次进程，不影响用户服务。
