## 面试题：代码库检索为什么不能只依赖向量相似度？

### 回答框架

代码问题常涉及精确符号、配置项、错误文本和调用关系，纯语义检索可能漏掉真正入口。先结合文件名与文本搜索定位，再使用符号、引用和语义检索补充。检索结果是线索，修改前需读取当前源文件及相邻测试。

### 关键机制与取舍

- 从报错、路由、导出符号或配置入口追踪调用链，确认实际运行路径。
- 排除生成产物与无关依赖噪声，但必要时读取锁定版本的依赖实现。
- 索引与当前提交同步，保留路径和位置，避免用过期片段生成补丁。

### 场景与失败处理

搜索命中同名旧函数，Agent 修了未被调用的实现。通过引用和路由确认实际入口，再用失败样例验证行为确实改变。

### 常见追问

**大仓库先整读好吗？** 通常不，分层定位可以降低噪声与上下文成本。

**找不到符号怎么办？** 检查别名、生成代码、动态注册与配置映射，而不是直接假定功能不存在。
