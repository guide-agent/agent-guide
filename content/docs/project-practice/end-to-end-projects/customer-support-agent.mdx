## 面试题：客服 Agent 如何兼顾回答质量与业务权限？

### 回答框架

将知识问答、账户查询、工单创建和退款等动作按风险分层。回答需要可追溯知识与实时状态，操作需要身份、规则和必要审批。目标不是尽可能少转人工，而是在正确解决问题的同时控制误承诺和误操作。本页不代表真实上线案例。

### 关键机制与取舍

- 按租户和版本检索政策，结合真实订单状态，不把过期 FAQ 当当前业务规则。
- 工具只开放授权动作，退款金额和对象必须在服务端验证。
- 人工交接保留问题摘要、已核对信息和已发生动作，避免用户重复描述。

### 场景与失败处理

知识库说七天可退，但商品属于例外类别。模型不能只引用一般政策就执行退款，应调用业务规则服务并说明适用条件。

### 常见追问

**如何测质量？** 分别测解决率、事实正确、误承诺、越权、转人工质量和单位成功成本。

**情绪安抚能替代问题解决吗？** 不能，礼貌只是交互质量，业务结果和真实执行还要独立验收。
