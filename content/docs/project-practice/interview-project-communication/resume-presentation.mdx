## 面试题：简历中的 Agent 项目怎样写得具体且可信？

### 回答框架

用职责、关键行动和可验证结果描述经历，技术词只服务于解释贡献。个人练习、开源贡献和生产项目应明确区分。量化有助于比较，但数字必须有来源；不能把模板里的 QPS、准确率或收益替换成自己的经历。

### 关键机制与取舍

- 每条突出一个主要贡献，写清作用范围与技术决策，而非堆十个框架名称。
- 指标附必要口径：评测集、环境、时间范围和质量门槛；实验提升不冒充生产收益。
- 准备可公开或脱敏的证明材料，尊重客户数据、公司保密和协作归属。

### 场景与失败处理

完成过开源 Agent 的本地改造，可以写实现了哪些接口、恢复测试和文档；未接入真实流量时不写“服务百万用户”。

### 常见追问

**课程项目能写吗？** 可以，标明来源、个人新增工作和验证范围，不把教程原功能都算本人贡献。

**没有漂亮数字怎么办？** 写可核查交付与问题解决，补真实实验后再添加指标。
