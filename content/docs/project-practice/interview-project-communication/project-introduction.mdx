## 面试题：如何用两分钟介绍一个真实 Agent 项目？

### 回答框架

按业务问题、个人职责、关键决策、验证结果和不足组织，而不是从技术栈清单开始。先让面试官理解为什么做、你具体负责什么，再选一个能深入追问的技术难点。没有上线或性能数据时应直说，不借用开源项目的数字。

### 关键机制与取舍

- 背景交代用户、场景和约束，目标说明验收标准，不把学习 Demo 描述成企业生产系统。
- 行动讲清为何选该方案、比较过什么，以及失败时怎样处理。
- 结果注明数据来源、样本和时间范围，区分团队产出与本人贡献。

### 场景与失败处理

如果只负责检索模块，就说明自己实现了索引更新与权限过滤；不要因为项目包含多 Agent 就声称设计了整个编排系统。

### 常见追问

**没有量化结果怎么表达？** 可提供可复现用例、交付功能与已知限制，之后补实验，不能捏造提升百分比。

**项目介绍要讲失败吗？** 选一个有证据且能说明改进的失败，比笼统声称“完全稳定”更可信。
