## 自测与使用边界

能区分自己实现、参考思路、教学示例与尚未验证的假设，不编造业务规模或性能收益。

阅读后尝试不看答案回答主问题，再用失败场景追问自己的设计。概念说明、设计建议与运行结果应分开记录。

参考来源、快照日期和版权边界见 [参考资料](/docs/references)；统一写作与验收约定见 [使用说明](/docs/guide)。
