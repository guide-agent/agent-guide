## 面试题：如何证明一次性能优化没有用质量换速度？

### 回答框架

固定模型、数据、请求分布和质量门槛，先定位耗时与费用，再改变主要瓶颈。比较端到端结果而非孤立阶段。缓存、压缩、小模型路由和并发都可能改变质量，需要同时保留失败切片与成本明细。

### 关键机制与取舍

- 拆分排队、检索、模型、工具和结果处理，观察 P50 与尾延迟而非只有平均值。
- 记录冷启动、热缓存、输入输出长度和并发，确保优化前后可比。
- 费用按成功任务核算，计入重试、额外模型和工具调用，不隐去人工接管成本。

### 场景与失败处理

关闭重排序后平均延迟下降，但复杂查询回答错误增加。应按查询切片决定是否条件启用，而不是宣称整体性能提高就全面删除。

### 常见追问

**实验数字可以写成生产收益吗？** 不能，要说明环境、样本和限制；生产收益需要真实观测。

**能一次改多个优化项吗？** 可以作为综合试验，但很难归因，关键因素最好做消融。
