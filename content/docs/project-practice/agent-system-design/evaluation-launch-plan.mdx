## 面试题：上线方案如何连接质量评估与运行风险？

### 回答框架

上线前定义任务成功、约束违反、延迟、费用和人工接管门槛，离线评测覆盖目标分布与失败路径。上线时用可控流量和可撤销配置验证真实效果；回滚方案必须考虑已发生副作用与状态版本。

### 关键机制与取舍

- 准备正常、攻击、权限、工具故障和恢复用例，业务侧确认验收标准。
- 灰度版本固定到任务，监测质量与成本切片，达到停止条件就停止扩量。
- 交付运行说明、告警责任、数据保留和恢复流程，而非只给一个可启动镜像。

### 场景与失败处理

新版本更会使用工具，但误操作率增加。上线门槛应让严重越权独立触发回滚，不能被总体成功率提升抵消。

### 常见追问

**没有线上流量能验收吗？** 可完成离线与受控试用验收，但要明确生产效果仍未验证。

**回滚窗口怎么定？** 结合任务最长运行时间、状态兼容与外部影响，不能只参考发布耗时。
