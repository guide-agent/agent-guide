## 面试题：模型 SDK 与 Agent SDK 的边界是什么？

### 回答框架

模型 SDK 主要封装模型请求、响应与认证；Agent SDK 往往进一步管理工具调用循环、会话、交接或运行事件。能力因产品和版本不同而变化。采用 SDK 不意味着业务授权、持久化策略和幂等性可以交给默认配置。

### 关键机制与取舍

- 先确定所需生命周期：单次调用、长任务、人工暂停或会话恢复，再核对 SDK 是否真正覆盖。
- 业务工具与模型适配层解耦，输出转成稳定内部契约，避免厂商响应结构扩散到全系统。
- 核对流式错误、取消、调用上限和数据处理条款，固定依赖版本后做契约测试。

### 场景与失败处理

SDK 在内存中保存会话，进程重启后任务消失。需要明确持久会话与运行时会话的区别，补充状态存储；不能仅因 SDK 有 session 名称就认为支持可靠恢复。

### 常见追问

**SDK 支持工具就能上线吗？** 还要处理权限、超时、幂等、日志脱敏及业务验收。

**迁移供应商难在哪里？** 除请求格式外，还有工具语义、流式事件、拒绝状态、上下文和计费差异。
