## 面试题：Agent 接入企业系统时，最容易漏掉哪些边界？

### 回答框架

外部集成不仅是调用 API，还涉及身份、资源归属、业务事务、速率限制和数据语义。应把已有系统能力封装成窄工具，保留原系统的权限与审计，不因为调用者是模型就开启管理员通道。

### 关键机制与取舍

- 明确用户委托与服务身份的区别，最小化凭证范围，读取与写入分开授权。
- 为写操作定义请求 ID、前置条件、幂等和结果查询；跨系统流程考虑补偿而非伪装成单一事务。
- 适配分页、时区、单位和字段版本，返回足够证据而不泄露完整内部记录。

### 场景与失败处理

CRM 同步在第二个系统失败，直接重跑全流程导致第一边重复客户。记录每步状态，查询已成功写入，并仅恢复失败边界。

### 常见追问

**为什么不用一个通用 HTTP 工具？** 业务专用工具更易约束地址、身份和副作用，通用工具需额外边界控制。

**外部 API 改版怎么办？** 固定契约、监控字段变化并准备兼容适配，不能只靠模型自动猜新字段。
