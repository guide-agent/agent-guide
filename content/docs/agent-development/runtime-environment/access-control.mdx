## 面试题：Agent 的有效权限由谁决定？

### 回答框架

有效权限由用户授权、服务身份能力、资源策略和运行环境共同约束。模型只能请求动作，不能自行创造权限。工具层与业务服务都要验证身份与资源归属，不能仅用“隐藏工具按钮”或提示词作为访问控制。

### 关键机制与取舍

- 默认以可信会话绑定租户和用户，避免模型自由传入身份参数造成越权。
- 授权检查靠近执行，缓存权限时设置失效与撤销机制，长期任务恢复后重新确认。
- 记录动作、主体、资源和决策，但对凭证与敏感内容脱敏。

### 场景与失败处理

只允许查询用户自己的账单，却提供任意 account_id 参数。即使模型选择了别人账号，服务端也必须拒绝；不能把用户说“我是管理员”当有效身份。

### 常见追问

**RBAC 足够吗？** 角色能表达粗粒度能力，资源归属、时间和动作风险通常还需属性或业务条件。

**多 Agent 如何传递权限？** 传递受限委托和必要上下文，不共享一个无限权限服务账号。
