## 面试题：开发层如何实现可恢复、不可误用的人工审批？

### 回答框架

把审批建模为持久化状态：待批动作、参数摘要、请求人、审批者、版本和有效期。暂停时释放执行资源，批准后检查状态仍匹配再继续。它不是在内存里一直等待一个布尔变量。

### 关键机制与取舍

- 审批只授权具体动作与参数，参数变化、权限撤销或超时后需要重新确认。
- 审批 API 检查审批者身份与任务范围，记录拒绝、修改、取消和过期，而非只有同意。
- 恢复节点可能重执行，审批前后的外部副作用都要具备幂等或明确的执行记录。

### 场景与失败处理

用户批准向甲发送报告，Agent 在等待期间把收件人改成乙。执行器应发现审批摘要与当前参数不一致并停止，不能复用旧授权。

### 常见追问

**服务重启会怎样？** 审批记录与任务状态保留，恢复时重新核对待批动作和有效期。

**用户重复点击批准呢？** 批准和执行分别去重，确保一个审批不会重复触发外部操作。
