## Agent 是什么？

随处可见的招聘软件，到处都充斥着 Agent 的影子，那 Agent 到底是什么？面试的时候改怎么回答这个问题？

### 从 25 年的 [Google AI Agent](https://cloud.google.com/resources/content/ai-agent-handbook) 白皮书来理解

#### 定义

AI 智能体是语言模型（LM）的自然演进，标志着 AI 从被动的内容生成 / 预测工具（如回答问题、翻译文本），转向能自主规划、执行任务的独立应用。其核心区别在于 “自主闭环”：无需人类逐步指导，通过 “思考 - 行动 - 观察” 循环完成复杂多步骤目标，例如自动整理团队会议纪要并同步至日历、生成客户报告并合规审查等，这一转变让 AI 从 “辅助工具” 升级为 “协作伙伴”。

#### 架构组成

Agent = 模型 + 工具 + 编排层

##### 模型

作为推理引擎，负责处理信息、评估选项、制定决策，决定智能体的能力行为上限。

##### 工具

Agent 的双手，连接虚拟和现实。让大脑突破训练边界，获取外部知识。

##### 编排层

作为 “指挥中心”，管理智能体的 “思考 - 行动 - 观察” 循环，使其行动起来。

### 从[《深入理解 AI Agent》](https://github.com/bojieli/ai-agent-book.git) 来理解

#### 定义

现代 Agent 系统的本质可以用一个简洁的公式来表达：Agent = LLM + 上下文 + 工具。

#### 架构组成

##### LLMs

Agent 的大脑，理解意图、思考规划、做出判断。

##### 上下文

Agent 的眼睛：它不只是输入给模型的那段文本，而是 Agent 在每个决策点能看到的全部信息——环境信息、用户记忆、领域知识、自身状态和任务进展

##### 工具

Agent 的手脚：它不只是几个可调用的 API 函数，而是 Agent 能做的所有事情的集合。

AI 技术在不断与时俱进，日新月异的发生变化。不可拘泥于一藕，应当以探索，求知的心理应对变化。Agent 的本质是 LLMs 应用的扩展，基于 Context（Prompt） + Tool Call 不断衍生发展。

## LLMs 是什么？

Large Language Models (LLMs)：大语言模型，Agent 的基础底座。Agent 本质是对 LLMs 的调用。

## 普通应用和 Agent 应用有什么区别？

这里我们需要区分下普通应用，LLMs 应用和 Agent 应用。

### 普通应用

顾名思义，泛指所有的未接入 LLMs 的应用。普通的业务服务，比如淘宝，京东等。

### LLMs 应用

在应用程序中，LLMs 只提供用户回答，一次交互的模式，问什么回答什么。没有 Tool Call API 的模型。处于 AI 应用的最早期阶段。

### Agent 应用

基于 LLMs 之上的高级 AI 应用，Agent 本身具有外界感知，思考能力。结合 RAG、ReAct等技术手段设计的多轮 LLMs 调用的应用。

## 开发 Agent 应用需要什么技术，什么能力？

首先，需要明确的是，Agent 应用脱胎于业务技术，业务技术该学习掌握的东西不会因为 Agent 而发生变化。恰逢 Coding Agent 盛行，屏蔽了大多数人的 Coding 水平差异，此时更应该掌握底层技术，具有设计思维。解决 Coding Agent 解决不了的问题。
