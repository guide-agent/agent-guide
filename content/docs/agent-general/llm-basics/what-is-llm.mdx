## 面试题：大语言模型是什么，它和搜索引擎有什么区别？

### 30 秒回答

大语言模型是在大量数据上训练出来的语言处理模型。常见的生成式模型会根据已有上下文，逐步预测并生成后续 token。它能写作、分类、总结和辅助推理，但回答流畅不代表事实正确。搜索引擎主要查已有资料；模型主要生成内容，二者可以通过 RAG 结合。

### 用一个例子理解

让模型把一封投诉信归纳成三点，是利用它处理语言的能力；问“今天订单为什么还没到”，则需要查询实时订单系统。模型即使能写出很像客服的回答，也不代表它真的查过订单。

## 什么是大模型

大语言模型（Large Language Model，LLM）通过大规模数据训练，建模和生成语言。“大模型”是更宽泛的说法，还可包含视觉与多模态模型。是否支持语音、图像取决于具体模型与接口。

### 大规模参数

模型规模没有统一的“大模型”分界。参数数量影响容量，但效果还取决于训练数据、架构、训练方法与任务，不能只按参数量排名。

### 复杂计算结构

大模型基于深度学习架构，通常使用以下结构：

- **变换器（Transformers）**：如 BERT、GPT、T5 等，这些模型在处理序列数据（如文本）时表现出色。变换器通过自注意力机制来理解输入数据中不同部分之间的关系。
- **卷积神经网络（CNNs）**：虽然主要用于计算机视觉任务，但也可以在某些文本处理任务中使用。

#### 自注意力机制

变换器的核心机制之一是自注意力：让当前位置根据内容与其他可见位置交换信息。具体模型可以采用仅编码器、仅解码器或编码器与解码器组合，并非都必须同时有两者。

#### 自监督预训练

语言模型通常通过自监督目标进行预训练，例如预测后续 token 或恢复遮蔽内容，再进行指令微调、偏好优化等后训练。自监督可以使用未人工标注的数据，但仍然有训练目标。

## 大模型的功能

### 文案写作

可以起草产品文案、改写语气或整理邮件。是否符合事实、品牌要求和引用规则，仍需检查。

### 知识库回答

可以读取检索系统提供的资料，组织成带出处的回答。但必须区分模型自身生成的内容和实际查询到的证据，不能假定每个回答都经过搜索。

### 文本分类

LLM 可以通过提示、示例或任务训练进行文本分类。分类通常判断预定义标签，聚类则发现数据分组，二者不是同一过程；Embedding 也可供传统分类器或聚类算法使用。

### 代码生成

LLM 在根据自然语言提示生成代码方面表现出色。Amazon Q Developer 允许用户使用 Python、JavaScript、Ruby 等多种编程语言进行编程。它还可以用于创建 SQL 查询、编写 Shell 命令和设计网站等。

### 文本生成

文本生成确实可以用于补全不完整的句子、编写产品文档，甚至创作儿童故事等。这种能力使得大模型在内容创作方面非常灵活和实用。

## 大模型的分类

这里说了大模型，那什么是”小模型“？

### 小模型

#### 小模型的定义

“小”是相对规模，不代表结构一定简单或层数一定很少。较少参数通常有利于减少权重存储，但部署效果还取决于架构、精度、硬件和任务。可在资源受限场景中评估，例如：

- **移动端应用**：在手机或平板上运行，避免过度消耗电池和计算能力。
- **嵌入式设备**：如智能家居设备、传感器等，这些设备通常计算能力较弱。
- **物联网（IoT）**：在分布式设备中进行实时处理和决策。

#### 小模型与大模型的区别

- **参数规模**：参数量可以来自层数、宽度等变化，不能只数层数判断大小。
- **任务能力**：必须在目标任务上比较，较小的专用模型也可能优于较大的通用模型。
- **计算资源**：权重存储与实际计算量不是一回事；模型架构、上下文长度、批处理和数值精度都会影响资源需求。

#### 涌现能力

某些能力随训练规模变化呈现非线性提升，常被讨论为“涌现”。现象受任务和测量方法影响，不能作为判定大小模型的统一标准，也不能代替业务评测。

### 模型分类

大模型可以根据不同的**特征和应用场景**进行多种分类：

#### **按模型架构分类**

- **变换器（Transformers）**：如 BERT、GPT、T5 等，广泛应用于自然语言处理（NLP）任务。
- **卷积神经网络（CNNs）**：主要用于图像处理和计算机视觉任务，如 ResNet、EfficientNet 等。
- **递归神经网络（RNNs）**：适合处理序列数据，如 LSTM 和 GRU，虽然近年来逐渐被变换器取代。

#### **按任务类型分类**

- **语言模型**：用于文本生成、补全和理解，例如 GPT 系列和 BERT。
- **图像处理模型**：用于图像分类、目标检测和图像生成，如 EfficientNet 和 GAN（生成对抗网络）。
- **多模态模型**：能够处理多种类型的数据（如文本和图像），例如 CLIP 和 DALL-E。

#### **按训练方式分类**

- **监督学习模型**：通过带标签的数据进行训练，例如图像分类的 CNN 模型。
- **无监督学习模型**：利用未标记的数据进行训练，例如自编码器（Autoencoders）。
- **自监督学习模型**：利用数据本身生成标签进行训练，例如 BERT 使用的掩蔽语言模型技术。

#### **按规模分类**

- **小模型**：参数量适中，适合在资源有限的环境中使用。
- **大模型**：在具体领域语境中指较大规模模型；不能仅凭固定参数阈值或规模断言其任务能力。

#### 按领域分类

- **通用模型**：可以用于多种任务，例如 OpenAI 的 GPT-3。
- **专用模型**：针对特定任务或行业优化的模型，例如医疗影像分析模型。

#### 按输入不同

甚至我们还可以根据输入的不同，将其划分为：

- **语言大模型（NLP）**：通常用于处理文本数据和理解自然语言。这类大模型的主要特点是它们在大规模语料库上进行了训练，以学习自然语言的各种语法、语义和语境规则。例如：GPT系列（OpenAI）、Bard（Google）、文心一言（百度）。

- **视觉大模型（CV）**：计算机视觉（Computer Vision，CV）领域中使用的大模型，通常用于图像处理和分析。这类模型通过在大规模图像数据上进行训练，可以实现各种视觉任务，如图像分类、目标检测、图像分割、姿态估计、人脸识别等。

- **多模态大模型**：是指能够处理多种不同类型数据的大模型，例如文本、图像、音频等多模态数据。其结合了NLP和CV的能力，以实现对多模态信息的综合理解和分析，从而能够更全面地理解和处理复杂的数据。

## 大模型当前面临的问题

### 知识与泛化边界

权重中的知识具有时间与覆盖限制，但模型可以使用上下文、检索和工具获取新事实。模型也能泛化到训练中未见的表达；这不意味着所有领域、长上下文和组合任务都可靠。评测需要覆盖实际业务分布。

### 数据安全

推理时发送数据、服务端留存数据和将数据用于训练是不同问题。企业需要根据授权、数据分类、服务条款和部署方式决定边界，不应一概认为所有 API 数据都会被训练，或使用私有模型就没有泄露风险。

### 上下文学习与长期记忆

通常的推理不修改模型权重。模型利用当前输入中的示例与新事实，不等于参数实时学习；跨调用的信息延续由应用保存会话、状态或记忆，并按需要再次注入。保存越多历史也不必然更好，还需过滤过期、冲突和越权信息。

### 偏差与幻觉

偏差可能来自数据分布、训练目标与交互方式；幻觉通常指缺乏依据或与事实不符的输出，二者不能画等号。人类条件反射或“神经元权重打满”的类比不构成技术解释。工程上应通过证据、校验、权限与评测降低风险，而不承诺完全消除错误。

## 面试追问

**预训练、后训练与推理有什么区别？** 预训练学习广泛数据模式，后训练调整行为与任务适配，通常推理使用已有权重处理新输入。上下文变化并不等于模型参数更新。

**参数越多越适合 Agent 吗？** 不一定，需比较工具调用、长任务、约束遵循和单位成功任务成本。小模型、确定性程序与大模型可以组合。

**如何验证回答是否正确？** 可执行任务检查实际状态和测试；事实回答核对可信来源；开放问题使用明确标准与人工抽检，而非仅看表达自信程度。
