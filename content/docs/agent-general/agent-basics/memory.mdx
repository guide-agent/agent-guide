## 面试题：短期记忆、长期记忆与知识库如何区分？

### 30 秒回答

短期记忆记住“这次正在做什么”，长期记忆保存“下次仍有用且允许保留的信息”，知识库存放“可查阅的资料”。它们不是同一个抽屉。信息要能更新、纠错和删除，不能把所有聊天记录永久保存就叫记忆系统。

### 用一个例子理解

“这次用中文写报告”先属于当前任务状态；“以后请默认中文”才可能成为长期偏好；公司报告模板属于知识库。三者都可能被检索出来，但谁能看、保存多久、如何纠正，需要分别规定。

### 关键机制与取舍

- 把事实、偏好、任务状态与经验分开存，记录来源、时间、适用范围和置信度。
- 写入需要依据与权限，用户纠正优先于旧推断；冲突通过版本或明确规则处理，而不是让相似度决定真伪。
- 支持删除、过期和跨租户隔离；召回结果进入上下文前仍要核对适用条件。

### 场景与失败处理

用户临时说“今天寄到办公室”，系统却长期覆盖家庭地址。应把当次收件地写入订单状态，只有明确长期变更才更新用户资料，并保留可回滚版本。

### 常见追问

**向量库是必需的吗？** 不是；精确用户偏好、账务和任务状态通常更适合结构化存储。

**记忆命中率高就好吗？** 还需衡量相关性、过期率、误用率和实际任务收益，错误记忆命中可能更危险。
