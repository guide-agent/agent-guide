## 面试题：如何区分 Agent、聊天机器人与固定工作流？

### 30 秒回答

区分 Agent 与固定工作流，最简单的问题是“下一步由谁决定”。工作流按预先写好的步骤走；Agent 会根据目标和刚获得的结果，在允许的动作中选择下一步。有没有聊天框、有没有调用工具，都不能单独作为判断标准。

### 用一个例子理解

程序固定执行“查快递、返回结果”，是工作流。系统发现快递长时间未更新后，自主决定先查物流公告还是联系人工，才体现 Agent 的动态决策。真正发消息或改订单，仍必须受到权限和业务规则约束。

### 关键机制与取舍

- 明确目标、可用动作、观察和停止条件；不要求一定有长期记忆或独立的规划模型。
- 工具调用也能由固定程序编排，单次函数调用不能单独证明系统具有自治闭环。
- 比较自治收益与验证成本，财务入账等规则清晰的步骤优先保留确定性控制。

### 场景与失败处理

“查订单再按规则退款”的固定流程未必需要 Agent；当用户问题模糊、需要多源排查时可让 Agent 检索，真正退款仍由明确授权和业务规则控制。

### 常见追问

**RAG 应用就是 Agent 吗？** 不一定；固定检索后生成是工作流，动态决定检索与行动才体现自治。

**Agent 越自主越好吗？** 不，自治范围应与任务收益、可观测性和错误代价匹配。
