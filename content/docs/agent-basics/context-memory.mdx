## 问题：上下文和记忆有什么区别？

上下文是模型在当前推理请求中实际可见的信息；记忆是系统为了跨步骤或跨会话保留的信息。记忆只有经过检索、筛选并注入当前请求后，才会成为上下文。

常见层次包括：

| 层次 | 典型内容 | 生命周期 |
| --- | --- | --- |
| 当前上下文 | 系统规则、用户请求、近期工具结果 | 单次模型请求 |
| 运行状态 | 计划、已完成步骤、预算、临时变量 | 单次任务 |
| 会话记忆 | 用户偏好、讨论结论、未完成事项 | 多轮会话 |
| 长期知识 | 文档、历史案例、结构化事实 | 跨会话 |

## 问题：上下文窗口不够时怎么处理？

优先保留不可替代的信息：系统约束、当前目标、未完成步骤、关键决策和最新观察。可重新获取的原始日志或长文档可以存储在外部，只把定位信息和摘要放入上下文。

摘要需要保留事实来源、不确定性和未决问题，避免把推测压缩成事实。对于需要精确引用的内容，应重新读取原文，而不是依赖多次压缩后的摘要。

## 问题：长期记忆写入什么内容？

长期记忆应保存未来确实有复用价值、来源明确且允许持久化的信息，例如稳定偏好、已确认决策和可复用故障经验。不应默认保存敏感数据、一次性上下文、未经确认的推断或容易过期的状态。

记忆系统还需要写入时间、来源、适用范围和失效条件，并提供更新与删除机制。
