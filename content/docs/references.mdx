## 资料如何筛选与使用

检索与获取日期：**2026-10-21**。使用 GitHub 的 `LLM interview questions`、`AI Agent interview`、`kubernetes interview questions`、`k8s-dra`、`GPU virtualization DRA` 等关键词，再定向核对厂商与产品官方仓库。筛选看主题覆盖、可读取正文、维护情况、原始资料入口和许可，不把 Star 当正确性证明。

## 入门补充：Jimmy Song《AI 基础设施手册》

按用户提供的 [手册入口](https://jimmysong.io/zh/book/ai-infra/)，于 **2026-10-21** 定向读取以下 8 篇章节，不声称阅读了全书。站点页脚标注 **CC BY 4.0**，具体第三方材料仍需单独核对许可。本站保留作者与来源链接，采用独立场景和措辞组织扫盲说明，没有复制原文图表、代码或部署示例。

- [GPU 基础认知](https://jimmysong.io/zh/book/ai-infra/fundamentals/gpu-basics-hardware-to-kubernetes/)：补充显存、计算、带宽和设备互连的入门区别。
- [GPU 显存管理](https://jimmysong.io/zh/book/ai-infra/fundamentals/gpu-memory-management/)：补充主机内存与设备显存、缓存与实际占用、OOM 排查顺序。
- [K8s 设备资源模型](https://jimmysong.io/zh/book/ai-infra/fundamentals/k8s-device-model/)：补充扩展资源与 Device Plugin 的基本链路。
- [硬切分与软切分](https://jimmysong.io/zh/book/ai-infra/fundamentals/hard-soft-slicing/)：作为分类与取舍的阅读入口，不把所有软件共享都当成有独立显存配额。
- [NVIDIA 软件栈](https://jimmysong.io/zh/book/ai-infra/software-stack/nvidia-software-stack/)：补充驱动、运行时、开发工具链与容器接入的职责区分。
- [DRA](https://jimmysong.io/zh/book/ai-infra/data-plane/dra/)：补充从整数资源计数到设备声明的学习路径。
- [GPU 资源控制面地图](https://jimmysong.io/zh/book/ai-infra/control-plane/control-plane-map/)：区分设备分配、队列准入、调度和运行时隔离，不据此承诺任意项目组合兼容。
- [GPU 指标语义](https://jimmysong.io/zh/book/ai-infra/observability/gpu-metrics-semantics/)：提醒先确认指标含义，再关联服务性能；不照搬监控字段编号与告警阈值。

**使用边界：** 获取时这些章节均标有“草稿”，不同页面的 DRA 版本表述存在不一致。本站不采用其版本时间线、CEL 示例、共享热调整或性能保证；设备与 API 行为以对应版本的官方说明为准。显存缓存和利用率的说明另经 PyTorch 与 NVIDIA 官方资料核对。
