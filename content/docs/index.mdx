## 如何选择阅读路线

- **Agent 应用开发**：通识 → 架构 → 开发 → 工程，再选择一个项目场景验证设计。
- **Coding Agent**：工具与上下文基础 → AI Coding 方法与原理 → 产品实践与固定版本源码。
- **算力基础设施**：GPU 共享机制 → Kubernetes 设备分配 → DRA 生命周期 → 隔离与性能验收。

旧版 [Agent 核心题库](/docs/agent-basics) 保留原路径便于既有链接访问；完整主题以新版九个栏目为主。

## 推荐回答结构

1. 先给出定义和结论。
2. 说明关键机制或数据流。
3. 分析适用场景与限制。
4. 给出工程实现或故障案例。
5. 补充指标、验证方法和改进方向。
