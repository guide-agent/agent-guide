## 面试题：Supervisor 如何分工，才不会变成新的单点瓶颈？

### 回答框架

Supervisor 负责分配任务、检查产物和决定后续步骤，工作 Agent 承担限定职责。主控不应反复重写所有细节，而应使用结构化产物和验收规则减少通信。其决策仍需要预算、持久状态和恢复策略。

### 关键机制与取舍

- 分配任务同时给出输入证据、预期产物和权限范围，减少子任务凭空猜测。
- 主控检查证据和约束，不能只根据子 Agent 的“已完成”文本改变全局状态。
- 主控失败时通过任务登记与已提交产物恢复，防止重新分派造成重复外部写入。

### 场景与失败处理

调研、分析、写作由不同角色完成，主控发现引用不支持结论，应退回对应分析步骤而不是让所有角色从头再做。

### 常见追问

**Supervisor 需要最强模型吗？** 取决于决策复杂度，可先用规则和小模型完成可确定分派。

**如何防止无限打回？** 定义验收条件、最大返工次数和人工仲裁出口。
