## 面试题：Router 应该只看模型给出的意图分类吗？

### 回答框架

Router 为请求选择模型、工具或处理流程。分类模型只是一个输入，最终路由还需满足权限、数据地域、能力和预算约束。低置信度或多意图请求应允许澄清、拆分或回退，不能强行归入一个错误类别。

### 关键机制与取舍

- 确定规则可先筛选候选，再用模型区分模糊意图，降低不必要的模型调用。
- 记录路由理由和候选集，用混淆矩阵检查高风险类别被误分的比例。
- 回退只能在允许候选中进行；“主模型不可用”不构成放宽权限的理由。

### 场景与失败处理

客户用自然语言夹带退款请求，被路由到普通问答而获得退款承诺。高风险动作应经独立能力与授权检查，即使分类器判断错误也不能直接执行。

### 常见追问

**路由准确率足够高就能上线吗？** 还要按错误代价评估，少量高风险误分可能不可接受。

**一个请求有多个目标怎么办？** 拆出依赖任务分别处理，再由主流程统一验证结果。
